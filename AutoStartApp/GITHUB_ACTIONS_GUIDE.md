# GitHub Actions를 이용한 APK 빌드 가이드

이 가이드는 제공된 소스 코드를 GitHub에 올려 자동으로 APK 파일을 생성하는 방법을 설명합니다.

## 1단계: GitHub 저장소(Repository) 만들기
1. [GitHub](https://github.com/)에 로그인합니다.
2. 오른쪽 상단의 **+** 버튼을 누르고 **New repository**를 클릭합니다.
3. **Repository name**에 `AutoStartApp`과 같은 이름을 입력합니다.
4. 공개 범위(Public/Private)를 선택한 후 **Create repository**를 클릭합니다.

## 2단계: 소스 코드 업로드하기
가장 간단한 방법인 웹 업로드 방식을 설명합니다.
1. 제가 드린 `AutoStartApp_v2.zip` 파일의 압축을 풉니다.
2. 생성된 GitHub 저장소 페이지에서 **"uploading an existing file"** 링크를 클릭합니다.
3. 압축을 푼 폴더 안의 **모든 파일과 폴더**를 브라우저로 드래그 앤 드롭합니다.
   - 중요: `.github` 폴더와 `app`, `build.gradle` 등이 모두 포함되어야 합니다.
4. 하단의 **Commit changes** 버튼을 눌러 업로드를 완료합니다.

## 3단계: 자동 빌드 확인하기
1. 저장소 상단의 메뉴 중 **Actions** 탭을 클릭합니다.
2. **Android CI**라는 이름의 워크플로우가 자동으로 실행되는 것을 볼 수 있습니다. (노란색 아이콘)
3. 빌드가 완료될 때까지 약 2~4분 정도 기다립니다. 완료되면 초록색 체크 표시(`✓`)로 바뀝니다.

## 4단계: APK 다운로드하기
1. 완료된 **Android CI** 항목(가장 최근의 Commit 메시지 제목)을 클릭합니다.
2. 화면 하단의 **Artifacts** 섹션을 찾습니다.
3. **app-debug**라는 항목을 클릭하면 APK 파일이 포함된 압축 파일이 다운로드됩니다.
4. 다운로드된 파일의 압축을 풀면 최종 결과물인 `app-debug.apk`를 얻을 수 있습니다.
