# Android 13 Auto Start Tool

이 프로그램은 안드로이드 13 기기가 부팅된 후 특정 앱을 자동으로 실행해주는 도구입니다.

## 주요 기능
- `BOOT_COMPLETED` 브로드캐스트를 수신하여 부팅 완료 감지
- 사용자가 설정한 패키지명의 앱을 자동 실행
- 안드로이드 10 이상에서의 백그라운드 실행 제한을 우회하기 위해 '다른 앱 위에 표시' 권한 활용

## 설치 및 사용 방법
1. 이 프로젝트를 Android Studio에서 엽니다.
2. 기기에 앱을 빌드하고 설치합니다.
3. 앱을 실행하여 **'다른 앱 위에 표시 권한 허용하기'** 버튼을 눌러 권한을 부여합니다. (중요: 이 권한이 없으면 안드로이드 13에서 부팅 후 앱이 실행되지 않습니다.)
4. 자동 실행을 원하는 앱의 **패키지명**을 입력하고 '설정 저장'을 누릅니다.
   - 예: 유튜브 (`com.google.android.youtube`)
5. 기기를 재부팅하면 설정한 앱이 자동으로 실행됩니다.

## 안드로이드 13 대응 사항
- **Background Activity Launch 제한**: 안드로이드 10부터는 백그라운드에서 액티비티를 직접 시작할 수 없습니다. 이를 해결하기 위해 `SYSTEM_ALERT_WINDOW` 권한을 요청합니다.
- **Battery Optimization**: 기기에 따라 배터리 최적화 대상에서 이 앱을 제외해야 부팅 브로드캐스트를 안정적으로 받을 수 있습니다.
- **앱 실행 이력**: 앱 설치 후 최소 한 번은 직접 실행해야 시스템으로부터 브로드캐스트를 받을 수 있습니다.
